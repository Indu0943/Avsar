## 🎨 BACKGROUND IMAGE SPECIFICATIONS

### Technical Details
- **Resolution:** 1920 x 1080 pixels
- **Format:** JPEG (optimized)
- **Source:** Unsplash.com (Free, Commercial Use)
- **Quality:** 85% compression (optimal balance)
- **CDN:** Unsplash provides automatic CDN optimization

### CSS Implementation Pattern
```tsx
<div
  className="absolute inset-0 z-0"
  style={{
    backgroundImage: "url(IMAGE_URL)",
    backgroundSize: "cover",
    backgroundPosition: "center",
    backgroundRepeat: "no-repeat",
  }}
/>
```

### Overlay Pattern (for text readability)
```tsx
<div className="absolute inset-0 bg-gradient-to-b from-black/60 via-black/50 to-black/40 z-[1]" />
```
